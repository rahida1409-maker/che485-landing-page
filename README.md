# CHE485 Chemistry Laboratory – slide-style landing page

Single page for GitHub Pages: `index.html`, `files/`, `.nojekyll`.
Slides move left/right: arrows, swipe, keyboard (← →, Home, End), dots or the top tabs.

**Deploy:** new repo > upload everything > Settings > Pages > Deploy from branch > `main` / root.

**Fill in later:** open `index.html`, find `var LINKS` and paste URLs for `lessonPlan`, `announcements`, `introVideo`.
